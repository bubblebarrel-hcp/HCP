# Hash Community Platform Product Bible

# Chapter 2 --- Understanding Hash House Harriers

**Version:** 2.0\
**Status:** Living Document

## 1. Purpose

This chapter introduces the traditions, terminology, roles, workflows,
and concepts of Hash House Harriers so every contributor understands the
domain before building the platform.

## 2. What is Hash House Harriers?

Hash House Harriers (HHH) is a worldwide network of social running clubs
founded in Kuala Lumpur in 1938. Hashing combines running, walking,
exploration, storytelling, humour, friendship, and tradition.

## 3. Philosophy

-   Every Hash is unique.
-   Every kennel has its own traditions.
-   Community comes before performance.
-   Every run creates stories worth preserving.

## 4. Lifecycle of a Hash Run

1.  Planning
2.  Trail Creation
3.  Gathering / Chalk Talk
4.  Live Run
5.  Circle
6.  Trail Report
7.  Historical Archive

The platform is designed around this lifecycle rather than treating a
run as a single event.

## 5. Organizational Structure

Each Kennel operates independently and manages its own members,
officers, permissions, branding, and events.

## 6. Common Roles

### Grand Master (GM)

Leads the kennel and manages administration.

### Joint Master

Supports the GM.

### Hare Raiser

Coordinates future Hares.

### Hare

Creates, edits and publishes trails.

### Hash Scribe

Writes and publishes trail reports, assisted by AI if desired.

### Religious Adviser (RA)

Facilitates Circle traditions and records awards.

### Hash Cash

Responsible for finances and future donation integrations.

### On Sec

Handles announcements and communications.

## 8. Digital Trail

A Trail is composed of: - Route - Waypoints - Media - Comments -
Weather - Attendance - Stories - Hash DNA

## 9. Waypoints

Supported waypoint types include: - Beer Check - Water Stop - Check -
False Trail - Back Check - River Crossing - Hazard - Scenic Viewpoint -
Photo Spot - Finish

Each waypoint can contain photos, videos, audio, comments, reactions,
timestamps and GPS coordinates.

## 10. Hash DNA

Hash DNA is a first-class domain model representing the unique
fingerprint of every completed run.

Dimensions include: - Trail characteristics - Environment - Attendance -
Community engagement - Media - Trail report richness - Memorable moments

Hash DNA powers: - AI storytelling - Recommendations - Historical
comparisons - Memory search - Analytics - Future gamification

## 11. Domain Relationships

-   Users join multiple Kennels.
-   Kennels organize Runs.
-   Runs contain one Trail.
-   Trails contain many Waypoints.
-   Waypoints contain Media.
-   Runs have one Trail Report.
-   Runs have one Hash DNA profile.

## 12. Design Principles

-   Preserve traditions.
-   Treat every run as a story.
-   Design for offline use.
-   Respect local autonomy.
-   Preserve history permanently.

## Chapter Summary

This chapter defines the Hash domain and establishes Hash DNA as a
foundational model for the platform.
