# Purpose

This document defines the Run Capsule Explorer, the primary interface for discovering, navigating, and reliving every preserved Hash run.

The Explorer presents a Run Capsule as an interactive experience rather than a static page.

---

# Vision

Opening a Run Capsule should feel like opening a beautifully curated museum exhibit dedicated to one unforgettable Hash run.

Every interaction should reveal another layer of the story.

---

# Philosophy

History should be explored, not merely displayed.

Users should naturally move between maps, photos, reports, songs, awards, and conversations without losing context.

---

# Guiding Principles

- Exploration over navigation.
- Storytelling over data presentation.
- Context before statistics.
- Rich media without clutter.
- Consistent across mobile and web.

---

# Explorer Overview

The Explorer consists of interconnected sections:

- Hero Overview
- Timeline
- Interactive Trail Map
- Story Report
- Story Cards
- Media Gallery
- Circle
- Participants
- Passport Activity
- Analytics
- Related Capsules

Each section is independently accessible while remaining synchronized.

---

# Hero Overview

The Hero section displays:

- Run Number
- Run Name
- Date
- Kennel
- Theme
- Lead Hare
- Hash Scribe
- Attendance
- Hero Photograph
- AI Summary

The Hero serves as the Capsule's cover page.

---

# FR-EXPLORER-001 — Interactive Timeline

## Priority

Critical

Users may scroll through a chronological timeline of the entire Run.

Timeline entries include:

- Trail release
- Start
- Checks
- Beer Stops
- Scenic locations
- Circle
- Awards
- Trail Report publication

Selecting an entry updates all synchronized panels.

---

# FR-EXPLORER-002 — Synchronized Experience

Selecting any item updates related panels automatically.

Example:

Selecting a Beer Check updates:

- Map
- Photos
- Videos
- Story paragraph
- Comments
- Participants present

The Explorer always maintains contextual relationships.

---

# FR-EXPLORER-003 — Interactive Trail

Users may switch between:

- Planned Trail
- Live Trail
- Historic Replay
- Participant Contributions

Map selections synchronize with Story Cards and media.

---

# FR-EXPLORER-004 — Story Reading Modes

Readers may experience the Run Capsule as:

- Traditional article
- Timeline narrative
- Story Card view
- Interactive map
- Hash Time Machine
- Gallery-first mode

Readers choose the experience that suits them.

---

# FR-EXPLORER-005 — Dynamic Media Gallery

Media automatically groups by:

- Time
- Location
- Beer Check
- Circle
- Participant
- Photographer

Every media item links back to the associated Story Card.

---

# FR-EXPLORER-006 — Participant Explorer

Readers may browse:

- Hares
- Scribe
- Officers
- Visitors
- Members

Each participant links to their public Hash profile (subject to privacy settings).

---

# FR-EXPLORER-007 — Circle Experience

The Circle section includes:

- Songs
- Down-Downs
- Awards
- Announcements
- Photos
- Videos
- Quotes

The Circle is presented as its own chapter within the Capsule.

---

# FR-EXPLORER-008 — Related Capsules

The Explorer recommends related Capsules based on:

- Same Hare
- Same Kennel
- Similar trail
- Anniversary
- Shared visitors
- Nearby dates
- Historic themes

Recommendations encourage historical exploration.

---

# FR-EXPLORER-009 — Accessibility

The Explorer supports:

- Keyboard navigation
- Screen readers
- High contrast
- Adjustable text size
- Reduced motion mode

Accessibility features preserve the storytelling experience.

---

# FR-EXPLORER-010 — Offline Viewing

Previously viewed Capsules may be downloaded for offline exploration.

Downloaded content includes:

- Story Report
- Timeline
- Maps
- Media thumbnails
- Story Cards

Large media downloads remain optional.

---

# Business Principles

- Every Capsule should invite exploration.
- Rich history should remain approachable.
- Context creates meaning.
- Discovery strengthens community.
- Every Run Capsule should feel timeless.
