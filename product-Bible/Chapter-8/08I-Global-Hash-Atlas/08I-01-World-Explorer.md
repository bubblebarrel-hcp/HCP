# Purpose

This document defines the World Explorer, the primary navigation experience of the Global Hash Atlas.

The World Explorer allows users to discover Hash communities through geography instead of traditional search alone.

Every location in the Atlas becomes an entry point into stories, trails, people, traditions, and history.

---

# Vision

The World Explorer should feel like opening a beautifully illustrated atlas where every place tells a story.

Users are encouraged to wander, zoom, and discover.

Curiosity—not search—is the primary navigation model.

---

# Philosophy

Maps should inspire exploration.

Exploration should create friendships.

Friendships should preserve the Hash.

---

# Guiding Principles

- Discovery before destination.
- Geography creates context.
- History enriches exploration.
- Every zoom level tells a different story.
- Performance must remain smooth worldwide.

---

# Geographic Levels

The Atlas supports seamless navigation through:

- World
- Continent
- Country
- State / Province
- City
- Kennel
- Venue
- Trail
- Run Capsule

Transitions should feel continuous.

---

# FR-ATLAS-001 — World View

## Priority

Critical

The World View displays:

- Active Kennels
- Historic Kennels
- Upcoming Runs
- Featured Events
- Interhash locations
- Regional activity heatmaps

Markers intelligently cluster as users zoom out.

---

# FR-ATLAS-002 — Country Explorer

Selecting a country displays:

- Number of kennels
- Upcoming runs
- Historic runs
- Featured trails
- Anniversary events
- Visitor statistics
- Regional summaries

Country pages become living introductions to Hashing in that nation.

---

# FR-ATLAS-003 — City Explorer

Each city presents:

- Active kennels
- Historic kennels
- Meeting venues
- Trail hotspots
- Beer Check locations
- Popular routes
- Recent Run Capsules

Cities become hubs of local discovery.

---

# FR-ATLAS-004 — Kennel Explorer

Selecting a kennel opens:

- Kennel profile
- Officers
- Run schedule
- Historic archive
- Trail statistics
- Anniversary timeline
- Featured Run Capsules

The Atlas links seamlessly into the Kennel domain.

---

# FR-ATLAS-005 — Trail Explorer

Users may explore trails by:

- Difficulty
- Distance
- Surface
- Terrain
- Elevation
- Theme
- Hare

Trails remain subject to visibility settings.

---

# FR-ATLAS-006 — Discovery Filters

Users may filter results using:

- Country
- Kennel
- Date
- Run type
- Theme
- Distance
- Visitor-friendly
- Family-friendly (where applicable)
- Red Dress Runs
- Charity Runs
- Anniversary Runs

Filters update results instantly.

---

# FR-ATLAS-007 — Search Everywhere

Global search supports:

- Kennels
- Cities
- Countries
- Hares
- Scribes
- Run numbers
- Trail names
- Beer Checks
- Landmarks

Search results integrate with Atlas navigation.

---

# FR-ATLAS-008 — Geographic Breadcrumbs

Navigation displays the current geographic path.

Example:

World

↓

Africa

↓

Nigeria

↓

Abia

↓

Aba

↓

Aba Hash House Harriers

↓

Run #742

Users may jump back to any level.

---

# FR-ATLAS-009 — Saved Places

Users may bookmark:

- Countries
- Cities
- Kennels
- Trails
- Run Capsules

Bookmarks synchronize across devices.

---

# FR-ATLAS-010 — Offline Regions

Users may download regions for offline browsing.

Offline support includes:

- Maps
- Kennel information
- Run Capsules
- Basic media previews

Large media downloads remain optional.
