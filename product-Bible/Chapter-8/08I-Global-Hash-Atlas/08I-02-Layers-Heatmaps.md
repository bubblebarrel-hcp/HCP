# Purpose

This document defines the interactive map layers, heatmaps, historical overlays, and story mapping capabilities of the Global Hash Atlas.

These layers transform the Atlas from a navigation tool into a visual representation of the global Hash movement.

---

# Vision

The map should answer questions users never thought to ask.

Where are the oldest kennels?

Which mountain has hosted the most trails?

Which cities have the most visitors?

Where did last weekend's Hashes take place?

The answers should appear visually.

---

# Philosophy

Maps communicate patterns faster than lists.

Stories become more meaningful when viewed geographically.

Every layer reveals a different perspective of the Hash community.

---

# Guiding Principles

- Layers never overwhelm the map.
- Every overlay can be toggled independently.
- Smooth performance on mobile.
- Visual clarity over density.
- Respect privacy settings.

---

# Layer Categories

The Atlas supports multiple categories of layers:

- Community
- Trails
- Events
- History
- Environment
- Personal
- Analytics
- AI Insights

---

# FR-ATLAS-011 — Kennel Layer

Displays:

- Active Kennels
- Historic Kennels
- Dormant Kennels

Each marker reflects current operational status.

---

# FR-ATLAS-012 — Trail Layer

Displays:

- Published trails
- Historic trails
- Upcoming public trails
- Trail difficulty
- Trail type
- Trail frequency

Trails may be filtered independently.

---

# FR-ATLAS-013 — Run Capsule Layer

Displays every published Run Capsule geographically.

Markers expand into:

- Hero image
- Run number
- Date
- Kennel
- Quick summary

Selecting a marker opens the Run Capsule.

---

# FR-ATLAS-014 — Beer Check Layer

Displays:

- Historic Beer Checks
- Scenic refreshment points
- Famous Beer Stops
- Community favorites

Users may browse Beer Checks independently of runs.

---

# FR-ATLAS-015 — Heatmaps

Supported heatmaps include:

- Hash activity
- Attendance
- Trail density
- Visitor movement
- Photo density
- Story density
- Passport stamps

Heatmaps update dynamically.

---

# FR-ATLAS-016 — Historical Timeline Layer

A timeline slider allows users to travel through history.

Examples:

1940

↓

1960

↓

1980

↓

2000

↓

Today

The map updates to show the state of the Hash community during the selected period.

---

# FR-ATLAS-017 — Event Layer

Displays:

- Upcoming Runs
- Interhash
- Nash Hash
- Anniversary events
- Charity runs
- Red Dress Runs

Users can subscribe to selected event types.

---

# FR-ATLAS-018 — Environmental Layers

Optional overlays include:

- Terrain
- Elevation
- Satellite imagery (where available)
- Weather
- Sunrise/Sunset
- Rivers
- Protected areas

Environmental context enhances trail understanding.

---

# FR-ATLAS-019 — Story Layer

Story Cards appear directly on the map.

Markers reveal:

- Photos
- Quotes
- Videos
- Audio
- Historical notes

Users may browse the map as a collection of stories.

---

# FR-ATLAS-020 — AI Discovery Layer

AI may identify:

- Emerging Hash regions
- Frequently visited trails
- Historic milestones
- Significant anniversaries
- Similar trail networks
- Hidden historical connections

AI insights remain clearly identified.

---

# Business Principles

Every layer should answer a meaningful question.

Maps should invite curiosity.

History should become visible.

Exploration should remain joyful.

---

# Completion Criteria

Complete when:

- Layer system is modular.
- Heatmaps function correctly.
- Timeline integrates with geography.
- Story mapping is implemented.
- AI insights remain transparent.
