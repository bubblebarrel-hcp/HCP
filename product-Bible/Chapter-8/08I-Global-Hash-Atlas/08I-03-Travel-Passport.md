# Purpose

This document defines how the Global Hash Atlas integrates with the Passport domain to create a rich travel experience for Hashers.

The Atlas should encourage exploration while the Passport records personal journeys across the global Hash community.

---

# Vision

Every journey leaves a trail.

Every trail earns a memory.

Every memory deserves a place on the map.

The Atlas transforms travel into a lifelong visual story.

---

# Philosophy

Hashing has always encouraged travel.

The Atlas should inspire users to discover new kennels, new traditions, and new friendships.

---

# Guiding Principles

- Travel should be celebrated.
- Memories should be visual.
- Discovery should remain organic.
- Privacy always comes first.
- Users own their travel story.

---

# FR-ATLAS-021 — Passport Mode

## Priority

Critical

Users may switch the Atlas into Passport Mode.

Passport Mode overlays personal travel information onto the world map.

Visited locations are visually distinguished from unexplored locations.

---

# FR-ATLAS-022 — Personal Travel Map

Each user has a Living Travel Map showing:

- Countries hashed
- Cities hashed
- Kennels visited
- Runs completed
- Passport stamps earned
- Favorite trails
- Wishlist destinations

The map updates automatically after each verified Run Session.

---

# FR-ATLAS-023 — Destination Explorer

Selecting a city or kennel displays travel-focused information:

- Upcoming runs
- Visitor friendliness
- Local traditions
- Meeting location
- Language(s)
- Climate
- Typical trail distance
- Local etiquette notes
- Contact officers (subject to privacy)

---

# FR-ATLAS-024 — Travel Wishlist

Users may bookmark destinations they hope to visit.

Wishlist entries may include:

- Personal notes
- Target year
- Friends attending
- Planned trips

The system may notify users about public events in wishlist locations.

---

# FR-ATLAS-025 — Suggested Adventures

The Atlas recommends destinations based on:

- Previous travel
- Passport progress
- Upcoming anniversaries
- Nearby public runs
- Similar trail preferences

Recommendations remain transparent and user-controlled.

---

# FR-ATLAS-026 — Journey Timeline

Users may replay their personal Hash journey chronologically.

The timeline includes:

- First Hash
- First visitor run
- First international run
- Passport milestones
- Major events
- Interhash participation

Each milestone links back to the relevant Run Capsule.

---

# FR-ATLAS-027 — Country Collections

Each country automatically builds a personal collection containing:

- All Runs attended
- Passport stamps
- Photos
- Favorite memories
- Friends met
- Historic notes

Collections become travel journals.

---

# FR-ATLAS-028 — Shared Adventures

Users may optionally share selected journeys.

Examples:

- My European Hash Tour
- Five Countries in Thirty Days
- Red Dress World Tour
- Across West Africa

Shared journeys link together multiple Run Capsules into one travel story.

---

# FR-ATLAS-029 — Global Statistics

Users may view personal statistics including:

- Countries visited
- Kennels visited
- Longest journey
- Total trail distance
- Highest elevation
- Continents explored
- Visitor runs completed

Statistics are calculated from verified participation.

---

# FR-ATLAS-030 — Privacy Controls

Users control visibility of:

- Travel map
- Passport stamps
- Country history
- Journey statistics
- Shared adventures

Private journeys remain excluded from public discovery.

---

# Business Principles

Travel builds friendships.

Friendships strengthen the Hash.

The Atlas should inspire—not pressure—exploration.

Every journey is unique.

---

# Completion Criteria

Complete when:

- Passport Mode exists.
- Living Travel Maps are supported.
- Wishlists function.
- Journey replay is implemented.
- Privacy controls are comprehensive.
