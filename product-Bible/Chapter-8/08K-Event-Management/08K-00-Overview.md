# Purpose

This domain manages every organized gathering within the Hash Community Platform, from weekly kennel runs to international multi-day events.

It provides the planning, registration, scheduling, logistics, operations, communications, and historical preservation required to deliver successful Hash events of any size.

---

# Vision

Every Hash event should be manageable from a single platform.

Whether organizing:

- Weekly Runs
- Full Moon Runs
- Red Dress Runs
- Charity Runs
- Campouts
- Anniversary Weekends
- Nash Hash
- Interhash

HCP should provide the tools needed to plan, execute, and preserve the experience.

---

# Philosophy

An event is more than a date.

It is a collection of people, places, trails, stories, logistics, traditions, and memories.

HCP should support the complete event lifecycle.

---

# Guiding Principles

- Plan collaboratively.
- Execute confidently.
- Preserve automatically.
- Minimize operational complexity.
- Keep participants informed.

---

# Event Categories

Supported event types include:

- Weekly Runs
- Full Moon Runs
- Pub Crawls
- Red Dress Runs
- Charity Events
- Family Hash
- Campouts
- Anniversary Celebrations
- Nash Hash
- Interhash
- Regional Gatherings
- Training Workshops
- Officer Retreats

Additional event types may be created by administrators.

---

# Event Lifecycle

Every event progresses through defined stages:

1. Draft
2. Planning
3. Registration Open
4. Registration Closed
5. Preparation
6. Live Event
7. Completed
8. Archived

Each stage unlocks specific capabilities.
