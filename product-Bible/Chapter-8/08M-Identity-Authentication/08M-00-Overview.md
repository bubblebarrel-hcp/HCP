# Purpose

This domain defines the identity model for every person, organization, service account, API client, and system process operating within the Hash Community Platform (HCP).

Rather than representing a login account, HCP Identity represents a person's long-term participation within the global Hash community.

Identity forms the foundation for authentication, authorization, governance, community relationships, events, passports, historical records, and future AI services.

# Philosophy

Roles change.

Passwords change.

Identity is permanent.

Everything else is attached to it.
