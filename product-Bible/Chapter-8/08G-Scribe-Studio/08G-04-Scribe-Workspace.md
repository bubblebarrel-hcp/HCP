# Purpose

This document defines the Scribe Workspace, the dedicated environment where Hash Scribes collect information, organize ideas, collaborate with reviewers, and produce the official Trail Report.

Unlike a generic document editor, the Scribe Workspace is purpose-built around the lifecycle of a Hash run.

---

# Vision

The Scribe Workspace should feel like a newsroom, archive, and creative studio combined.

Every important event from the run is already available.

The Scribe's task is not to remember everything.

It is to shape memories into an engaging story.

---

# Guiding Principles

- Minimize administrative work.
- Preserve editorial freedom.
- Keep storytelling enjoyable.
- Support collaboration without confusion.
- Protect historical integrity.

---

# Workspace Overview

The default workspace consists of:

- Story Timeline
- Story Card Library
- Rich Story Editor
- Interactive Trail Map
- Media Browser
- AI Assistant
- Reviewer Panel
- Version History
- Publishing Console
- Historical Reference Panel

Panels may be customized to match each Scribe's preferred workflow.

---

# FR-WORKSPACE-001 — Personalized Workspace

Each Scribe may customize:

- Panel arrangement
- Theme
- Font size
- Editor layout
- Default writing mode
- Preferred language

Workspace preferences synchronize across devices.

---

# FR-WORKSPACE-002 — Story Card Library

The Story Card Library contains every captured event from the Run Session.

Examples include:

- Beer Check
- Trail milestone
- Visitor introduction
- Award
- Circle event
- Song
- Photo
- Video
- Funny incident
- Officer announcement

Cards may be:

- Filtered
- Sorted
- Tagged
- Grouped
- Pinned

---

# FR-WORKSPACE-003 — Editorial Dashboard

The dashboard displays:

- Draft completion status
- Missing sections
- Unreviewed Story Cards
- Media awaiting captions
- Suggested AI improvements
- Pending reviewer comments

The dashboard helps the Scribe manage progress without interrupting creativity.

---

# FR-WORKSPACE-004 — Editorial Notes

The Scribe may maintain private notes separate from the published report.

Notes may include:

- Writing ideas
- Quotes
- Follow-up questions
- Future revisions
- Interview reminders

Editorial notes are never published.

---

# FR-WORKSPACE-005 — Collaborative Review

Where enabled, reviewers may:

- Suggest edits
- Comment on paragraphs
- Approve sections
- Request clarification
- Highlight factual inconsistencies

The Scribe remains the final decision-maker.

---

# FR-WORKSPACE-006 — Assignment Workflow

Large events such as Interhash may assign sections to multiple contributors.

Example assignments include:

- Trail coverage
- Circle summary
- Visitor interviews
- Awards
- Media captions

The official report is assembled into a single narrative before publication.

---

# FR-WORKSPACE-007 — Editorial Checklist

The workspace provides a configurable checklist including:

- Trail summary completed
- Beer Checks documented
- Circle recorded
- Awards included
- Media captions added
- Contributors acknowledged
- Privacy review completed

The checklist helps maintain consistency across reports.

---

# FR-WORKSPACE-008 — Historical Reference Panel

The Scribe may browse:

- Previous Trail Reports
- Anniversary reports
- Similar themes
- Historic photos
- Related Run Capsules

References remain read-only.

---

# FR-WORKSPACE-009 — Offline Editing

Drafts remain fully editable without network connectivity.

Changes synchronize automatically when connectivity returns.

Conflict resolution preserves all edits.

---

# FR-WORKSPACE-010 — Workspace Audit

The platform records:

- Draft creation
- Significant edits
- Reviewer comments
- Publication approvals
- Revision history

Audit records support transparency and long-term preservation.

---

# Business Principles

- The workspace should disappear behind the writing process.
- Collaboration should strengthen quality without slowing publication.
- Historical material should always be discoverable.
- Creativity should remain in human hands.
- The official report represents the voice of the community.

---

# Completion Criteria

This document is complete when:

- The workspace supports the full editorial workflow.
- Story Cards integrate seamlessly.
- Collaboration functions correctly.
- Offline editing is reliable.
- Editorial history is preserved.
