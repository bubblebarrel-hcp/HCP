# Purpose

The Communication Hub provides the unified communication infrastructure for the Hash Community Platform (HCP).

Rather than creating isolated messaging systems for each feature, HCP provides a shared communication service that supports conversations across events, organizations, governance, passports, trails, Run Capsules, committees, and future platform services.

The Communication Hub ensures every conversation remains contextual, searchable, secure, and historically meaningful.
