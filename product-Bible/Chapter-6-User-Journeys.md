# Chapter 6 --- User Journeys

## Purpose

Defines complete end-to-end user journeys that drive UX, APIs, database
design and testing.

### Journey 1: New Hasher

1.  Register
2.  Discover kennel
3.  Join kennel
4.  RSVP to run
5.  Download offline maps
6.  Attend run
7.  Upload media
8.  Read trail report

### Journey 2: Hare Creates Trail

-   Create/import GPX
-   Add waypoints
-   Configure beer checks
-   Set hidden release time
-   Publish

### Journey 3: Live Run

-   Trail released
-   Navigate
-   Check in
-   Upload media
-   Finish run

### Journey 4: Scribe

-   Review run
-   Generate AI draft
-   Edit
-   Publish report

### Journey 5: Visitor

Discover foreign kennel, RSVP, attend, contribute media.

### Journey 6: Offline Recovery

Continue navigation, capture media, sync later.

### Journey 7: Historical Archive

Run archived, Hash DNA finalized, searchable forever.

All journeys define personas, permissions, offline behaviour,
notifications and acceptance criteria.
