# Purpose

Chapter 21 defines the user experience system for HCP: who the product serves, how users think, how they move through the application, and how important tasks should behave from first entry through completion.

This chapter translates the product bible into implementation-ready experience guidance.

# Experience Traceability

Every journey should map to at least one task flow. See `21-05-Journey-Task-Flow-Traceability.md` for the matrix confirming this and recording coverage gaps.

Every task flow should define:

- Actor
- Trigger
- Preconditions
- UI flow
- Validation
- API or backend operations
- Success states
- Failure states
- Accessibility
- Analytics
- Acceptance criteria

---

# Completion Criteria

Chapter 21 is complete when:

- Core UX principles are documented.
- Primary personas and mental models are defined.
- Primary journeys are specified.
- Matching task flows exist for implementation.
- Navigation rules are documented.
- Accessibility, analytics, performance, and error recovery expectations are defined for each critical task.
