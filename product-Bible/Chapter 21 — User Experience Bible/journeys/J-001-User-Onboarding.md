# Journey Specification J-001

## User Onboarding

---

Document ID

HCP-JS-001

Status

Draft

Version

1.0

---

Purpose

Help a new user discover HCP, create an account, understand the platform, and successfully join their first community with confidence.

---

Primary Persona

Visitor

---

Secondary Personas

Community Member

---

Goal

Become an active community member.

---

Success Definition

The user:

✓ Creates an account

✓ Verifies identity (if applicable)

✓ Completes profile

✓ Joins first kennel

✓ Understands next step

---

Entry Points

• App Install

• Website

• Invitation Link

• QR Code

• Shared Event Link

• Community Referral

---

Preconditions

None

---

Trigger

User launches HCP for the first time.
