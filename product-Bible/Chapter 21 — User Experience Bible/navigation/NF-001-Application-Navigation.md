# Navigation Flow NF-001

## Application Navigation

---

Purpose

Define how users move between the major areas of HCP.

---

Navigation Philosophy

Users should never feel lost.

Every screen should answer:

• Where am I?

• What can I do?

• How do I leave?

• What changed?

---

Navigation Rules

Primary destinations

≤1 tap

Secondary destinations

≤2 taps

Deep destinations

≤3 taps

Never exceed 4 unless absolutely necessary.

---

Back Navigation

Back should return users to the previous context.

Never reset filters unless explicitly requested.

Never lose scroll position.

---

State Preservation

Remember

• Scroll

• Search

• Filters

• Open Tabs

• Expanded Sections

Restore when returning.

---

Cross Role Navigation

A Committee Member

should not see an entirely different app.

Instead

additional tools appear naturally.

The navigation model remains familiar.
